# JungleBerry Product Finder

An interactive e-commerce product recommendation experience created by Lazanti Global for JungleBerry.

## Live demo

[JungleBerry Routine Finder](https://jungleberry-routine-finder.danieldunsin.chatgpt.site)

## What it demonstrates

- Guided product-finder quiz for hair, face, and body care
- Personalized two- or three-product routine recommendations
- Recommendation explanations based on customer answers
- Conversion-focused product discovery and customer experience design
- Responsive front-end implementation using HTML, CSS, and JavaScript

The product mappings are a concept demonstration and should be validated with JungleBerry before production integration.
